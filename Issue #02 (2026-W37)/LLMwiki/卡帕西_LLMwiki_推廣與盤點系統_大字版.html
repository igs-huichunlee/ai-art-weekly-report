01. 概念與工具

核心工具與概念介紹

💡 一句話總結：「一個叫卡帕西的人建立AI圖書館的方式」
🧠

卡帕西 (Andrej Karpathy)

👤 「一個人」

前 OpenAI 創辦成員、Tesla AI 總監。提出將 LLM 視為作業系統 (LLM OS) 的構想——大模型是 CPU，而知識庫與 SKILLS 則是記憶體與周邊裝備。

📚

LLMwiki

📖 「AI圖書館」

專為 AI 與 Agent 設計的 Wiki 知識庫架構。將團隊 SOP、經驗規範與 Prompt 模組化，讓 AI 能快速精準地檢索與讀取上下文。

💎

Obsidian

📝 「記事本」

基於純 Markdown 檔案的雙向鏈結知識管理工具。資料完全自主可控，完美支援 Git 版本控制與本地 AI (Claude Code) 串接。

02. 價值與目標

可以幫助我們什麼？目標是什麼？

💡 可以幫助我們什麼？

  • • 打破知識孤島： 資源集中歸檔，知識全員共享。
  • • 賦能 AI 助理： 提供Agent團隊脈絡與背景知識，解決記憶缺陷。
  • • 極致提升效率： 實現一句話產出，節省重複試錯的時間與Token消耗。

🎯 我們的團隊目標

  • ✔ 建立標準化知識庫： 將團隊常用工作流程模組化，知識資產可持續累積。
  • ✔ 普及 Agentic 工作流： 全員熟練掌握 LLMwiki + Obsidian + Claude Code 組合技。
