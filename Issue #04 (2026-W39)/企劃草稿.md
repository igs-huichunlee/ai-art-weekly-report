## 1. 主題關鍵字

企劃原文（照抄，未潤飾）：

```
藍天、白雲、天空宮殿、紅燈籠、天宮、祥雲、元寶、清爽喜慶
```

### 美術方向定案（2026-09-21 蕙純確認）

- 走**明亮天宮場景 + 過年喜慶感**
- **不吃原皮惡魔之火的暗色／地獄氛圍**，但**保留「火焰」這個屬性特色**
- 也就是：場景明亮，火焰是金／赤色的祥瑞之火，不是業火

| 項目 | 內容 |
|------|------|
| 主色 | 紅色 |
| 輔色 | 明亮色系 |
| 火焰色 | 沿用舊產品必須有 |
| 禁用元素 | 黑暗 |
| 市場／地區 | 東南亞但是不用強調,需要維持通用性在 |

**❓Q4–Q6（配色）**：這三題是後面 10 幾張畫面能不能批量生成的關鍵。
只要色票沒定死，AI 每張畫面的天空藍會不一樣、每張的金會不一樣，拼起來就不像同一台機器。
建議直接從你定案的主畫面吸色，填 HEX，例如：

```
主色：天空藍 #4FA8E8 ／ 雲白 #F5FAFF
輔色：宮殿金 #F0C040 ／ 燈籠紅 #D93A2B
火焰色：赤金 #FF7A18 → #FFD24A（漸層兩端）
```

**❓Q7（禁用元素）**：原皮是「惡魔之火」，素材裡很可能有惡魔角、骷髏、暗紫色調這類元素。
明確列出「這次不准出現什麼」，外包才不會沿用原皮零件。我建議至少列：惡魔角、骷髏、黑紫色調、地獄岩漿地面。

**❓Q8（市場）**：影響字體、金額格式、禁忌顏色與符號。

## 2. 故事背景

企劃原文（照抄）：

```
在皇城之外，有一座終年被祥雲包圍的天空之城。這裡沒有戰亂，也沒有陰雨，被人們稱為「晴空福境」。
守護這片土地的是年幼的「天福神龍」。牠不像傳說中的巨龍那樣威嚴，反而十分喜歡人間的慶典。每當天空
最晴朗的日子，牠便會從雲海中探出頭，跟著燈籠與鐘聲來到城中，把自己收藏的金元寶偷偷放進人們的福袋
裡。
城中流傳著一個傳說：當三座「天福燈」同時被點亮，通往雲端寶庫的道路就會出現。神龍也會沿著金色祥雲
飛來，帶領幸運之人找到藏在天宮深處的財寶。
```

### ⚠️ 原文與定案方向的衝突（必須先解）

原文寫的是**「天福神龍」**、場景叫**「晴空福境」**，整段沒有任何火焰元素；
但專案名是**「烈焰神龍」**，且定案要保留火焰屬性。

**❓Q9**：龍的正式名稱是什麼？「烈焰神龍」還是「天福神龍」？
**這題沒定，後面每一張有龍的畫面、每一段外包說明、每一個 AI Prompt 都會用到不同名字。**
A9:烈焰神龍

**❓Q10**：故事裡的火焰要怎麼解釋？我的建議是把原文的「天福燈」升級成火的載體，例如：

> 「三座天福燈」改為「三盞赤焰天燈」——龍吐出的赤金祥火點亮天燈，
> 火不是災厄而是祥瑞，點亮三盞即開啟雲端寶庫。

這樣火焰有正當性、和「明亮喜慶」不打架，也接得上原文結構。**要或不要，或你有別的接法？**
A10:請詢問我和我討論詳細一些再做紀錄


**❓Q11**：龍的年齡外型。原文寫「年幼」「喜歡慶典」，是可愛幼龍路線；
但「烈焰神龍」聽起來是威嚴成龍。老虎機主視覺的龍通常要有壓迫感。**走哪個？**
A11:可愛的龍但初生之犢不畏虎,喜好追求能力的提升,目標是變成超越父親的神龍


**❓Q12**：龍要不要有「人形／擬人」形態？
因為第 4 節提到角色要持武器做互動演出，四足龍拿棍棒會很奇怪。
可能是：(a) 龍本體＋武器懸浮 (b) 擬人化龍人 (c) 另有一個持武器的角色，龍是坐騎／背景。
A12:可以稍微擬人化,但沒有真的變成人,武器可以和東方有關,或是純火焰的靈氣
