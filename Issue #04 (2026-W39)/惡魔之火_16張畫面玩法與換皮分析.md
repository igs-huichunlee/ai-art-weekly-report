## 1. 這 16 張圖呈現的遊戲骨架

這批圖可整理為一條主要體驗流程：

```text
主遊戲 MG（5×3、20 Lines）
  ↓ 命中 3 個 Scatter
免費遊戲輪盤出現
  ↓ 抽出 8／10／12／15 局之一
免費遊戲 FG 開始
  ↓ 每局先以 Jackpot Multiplier X1 開始
R2～R4 角色向同軸空位擴展
  ↓ 新增角色格數提高當局 Jackpot Multiplier
擴展後角色總數對應 Jackpot 3～9 等級
  ├─ 一般大獎：Big／Mega／Super Win
  └─ Jackpot：角色演出 → 武器演出 → 等級揭曉 → 金額揭曉
  ↓
免費遊戲結算：總贏分＋FG 統計資訊
```

後續換皮時，最需要保留的是這條節奏：**基礎盤面 → Scatter 期待 → 輪盤決定局數 → FG 特殊規則 → 分級高潮 → 總結算**。新主題與替換對照等收到另外的主題文件後再補，本文件暫不指定。

## 2. 共用畫面結構

### 2.1 遊戲核心區

- 橫版畫面，主要遊戲區置中。
- 盤面為 **5 軸 × 3 列**，標示 **20 LINES**。
- 左側固定有 3～9 共七級的 Jackpot 階梯表；級別越高，獎值越高。
- 上方中央為遊戲 LOGO；FG 時會改成狀態列。
- 右下有大型 Spin 按鈕；底部有 Balance、Bet、Win、自動遊戲等資訊。
- 盤面後方、左右背景與角色共同建立主題氛圍，但不得壓過轉輪符號與數字資訊。

### 2.2 平台共用 UI 與遊戲專屬 UI

畫面左右側的 Home、活動、Link Jackpot、Win More、Buy Bonus、Collection，以及底部 Bar，已確認屬於**平台共用 UI**。正式遊戲會換成目標平台的另一套共用 UI；若本次工作是重繪遊戲內容或製作概念拼板，應把這些共用 UI 拔除，不列入遊戲主題換皮資產。

較可能屬於遊戲專屬、需要跟著換皮的部分：

- 遊戲 LOGO。
- 中央盤框、盤底、轉輪遮罩與 20 Lines 牌。
- 左側 Jackpot 階梯表及角色。
- 轉輪符號、Scatter、Wild、角色 Jackpot 符號。
- FG 狀態列、輪盤及免費遊戲局數宣告。
- Big／Mega／Super Win 報獎。
- Jackpot 四階段報獎與結算畫面。
- `EX ?` 按鈕的視覺；其功能由截圖無法確認。

### 2.3 直版沿用原則

- 專案會有直版畫面。
- 直版大部分素材直接沿用橫版並縮小配置，不另做一整套新資產。
- **直版 Jackpot 框與背景需要重畫**，以符合直版比例與主要視覺區。
- 直版實際縮放比例、位置與安全區仍需在正式拼板時確認。
- 原資料夾沒有編號 02、03，是因為內容與其他畫面類似而由使用者主動移除，不代表缺少玩法狀態。

## 3. 逐張畫面分析

### 3.1 `01橫_MG.jpg`：主遊戲／Scatter 命中畫面

![01橫_MG](./01橫_MG.jpg)

畫面顯示一般主遊戲盤面。R2 出現 Wild，R3～R5 上排連續出現三個 Scatter，應是進入免費遊戲的觸發展示。盤面也同時展示角色、單／雙／三心、金幣、三叉戟、蠟燭、辣椒等符號。

**玩法資訊：**

- 5×3、20 線的固定盤面。
- **出現 3 個 Scatter 即進入免費遊戲。** Scatter 本身不直接支付獎金，後續輪盤只用來決定本次可玩的免費遊戲局數。
- Wild 是百搭符號，不會提供額外倍數；是否能替代 Scatter、Jackpot 角色等特殊符號，仍以程式規則為準。
- 左側 Jackpot 階梯表以 3～9 分級，與 Jackpot 報獎的中央數字徽章呼應。

**換皮重點：**

- Scatter 的輪盤意象可以換成符合新主題的「入口物」，但仍需一眼識別為觸發符號。
- Wild 應保留最高辨識度，文字或圖形不可和一般符號混淆。
- 角色 Jackpot 符號必須與後續 FG、Jackpot 報獎主角一致。

### 3.2 `04橫_R2~4特殊輪FG.jpg`：免費遊戲主盤面

![04橫_R2~4特殊輪FG](./04橫_R2~4特殊輪FG.jpg)

FG 畫面保留 5×3 盤面，但 R2～R4 是主要特殊區。上方 LOGO 改成 `JACKPOT multiplier X1` 與 `Free Game 20/20`；底部盤框出現一排灰色／紅色角色頭標記，應是收集、進度或倍率累積提示。

**影片確認的玩法資訊：**

- `Free Game 2/10` 代表「目前第 2 局／本次共 10 局」；影片由 `1/10` 走到 `10/10`。
- 每一局開始時 Jackpot multiplier 回到 `X1`，角色擴展過程中才逐步增加；影片可見同一局由 `X1 → X2 → X4 → X5`，下一局重新計算。
- R2～R4 是主要特色輪軸，畫面名稱也直接標示「特殊輪」。
- R1、R5 在畫面上較暗、較窄，強化中間三軸的功能焦點。
- R2～R4 出現角色後，角色會往同一軸的空位擴展；每補出一個新角色格，當局 Jackpot multiplier 會提高一级。影片中原有角色逐步補滿中間 3×3 九格，倍率最後到 `X5`。
- 底部共有 9 個角色頭標記，空間關係對應 R2～R4 的 3×3 九格；灰色代表未被角色佔據，紅色代表已佔據。擴展過程會同步由灰轉紅。
- 擴展完成後，中間 3×3 的角色總數對應 Jackpot 3～9 級。影片中九格全滿後觸發 `JACKPOT 9`。
- 左側 3～9 Jackpot 階梯金額會乘上當局 multiplier 並即時更新。影片中第 9 級基礎值 20,000，在 `X5` 時更新為 100,000，最終 Jackpot 9 報獎也數到 100,000。
- Big Win 等報獎會插入 FG 流程，報獎完成後才繼續後續 Free Game 局數。

**待確認：**

- 角色在同一軸有兩個以上時，程式是逐角色觸發擴展，還是先合併計算空位；靜態影格只能確認最終補位與倍率結果。
- Jackpot 等級是否只看擴展完成後的角色總格數，以及 3～8 級是否每次都進入完整 Jackpot 報獎；影片完整示範的是九格全滿的 Jackpot 9。
- 影片沒有展示 FG 中途再次增加局數的機制，因此本文件不先假設存在再觸發。

**換皮重點：**

- 新主題仍需讓玩家立刻知道 R2～R4 是玩法核心，可用框光、色溫、材質或局部背景區分。
- Jackpot Multiplier、Free Game 計數與進度標記不能只換美術而失去狀態可讀性。
- 角色擴展、九格進度、倍率數字、左側獎值更新與 Jackpot 等級必須同步，不能各自晚一拍或顯示不同結果。

![15橫_結算](./15橫_結算.jpg)

**資訊層級：**總金額最大，其次是結算標題，最後是免費遊戲統計。結算是整段 FG 的收尾高潮，需和單次 Big／Mega／Super Win 有明顯區別。

### 3.16 `FG流程.mp4`：動態流程補充

影片約 1 分 23 秒，完整示範以下時序：

1. 三個 Scatter 命中並以火焰路徑連結，角色進場。
2. Free Game 輪盤轉動，停在 10。
3. 獨立宣告確認取得 10 Free Games，並提示 R2～R4 擴展與 Jackpot multiplier。
4. FG 狀態列出現；每局顯示「目前局數／總局數」。
5. R2～R4 的角色向空位擴展，底部九格進度同步點亮，multiplier 隨新增格數提高。
6. 左側 Jackpot 階梯金額隨 multiplier 即時重算。
7. 九格角色全滿觸發 Jackpot 9，獎金以數字跳升至 100,000。
8. 後續局數繼續個別重算 multiplier，過程可插入一般線獎與 Big Win。
9. 第 10 局結束後顯示 FG 總結算，再回到 MG 畫面。

影片證明這套玩法的資訊不是單一結果視窗，而是四個同步層：**盤面角色擴展 → 九格進度 → Jackpot multiplier → 左側 Jackpot 金額／等級**。換皮時四層都要保留完整狀態與演出承接。

## 4. 換皮時必須保留的玩法特徵

### A. 盤面與資訊

- 5×3 轉輪與 20 Lines。
- Wild、Scatter、Jackpot 角色三種功能符號。
- 一套有明確賠付階層的七種一般符號：三個同家族高階符號、兩個中階符號、兩個低階符號。
- 左側 3～9 Jackpot 七級獎表及當前級別高亮。

## 8. 研一 F1 專案必須補充遵守的規格

本節只收錄《研一 F1 SLOT 總則》中跨案適用的通則。烈焰神龍及其他新主題的個案方向暫不加入，等使用者提供主題文件後再整理。

### 8.1 前、中、後景的固定層次

研一要求的視覺順序是：

```text
最前／最重要：整體盤面、功能符號、當次結果
中層：角色與主題道具
最後：背景環境
```

實作時需注意：

- **盤面必須是第一閱讀層。** 外框、角色或背景再精緻，也不能搶走盤面、獎級與數字資訊。
- **角色放在中層。** 角色要有故事性並參與輪盤、FG、Jackpot 演出，但常態畫面不能蓋住盤面核心區。
- **背景必須退後。** 降低背景對比、飽和度、細節密度與銳利度；避免在盤面邊緣製造大量高亮小物。
- **角色頭部附近不要放神光、放射線或高亮特效。** 這類元素會讓角色頭與盤面爭焦點；輪廓光只做必要的分層。
- 報獎畫面可以暫時提高角色與特效權重，但獎級和金額仍須比角色更容易閱讀。

原文件第 7 節已提到背景退後與單一焦點；本條進一步把它定義成研一固定排序，不能只當成建議。

### 8.2 大塊面優先，控制細節量

- AI 生成素材常有過多碎紋、金屬小零件、密集光點與無意義裝飾，需重新簡化。
- 角色、盤框、Symbol 都應先看**大輪廓與大色塊**，縮到實際遊戲尺寸後仍能辨識，再補少量重點細節。
- 細節集中在焦點區；背景和低階 Symbol 的細節要比高階 Symbol 少。
- 同系列素材不要每個都塞滿寶石、金邊、火焰與光暈。裝飾量本身也要形成高、中、低階。
- 盤框應用粗細、塊面與少量小細節建立品質，避免整圈都是同密度雕花。
- 評圖時除了原尺寸，也必須在 1600×1000 實際版面及遊戲顯示尺寸檢查；放大好看、縮小變成雜訊的細節應刪除。

### 8.3 畫面與素材尺寸硬規格

| 項目 | 研一 F1 規格 | 製作注意 |
|---|---|---|
| 底圖基準 | **1600×1000** | 版面、對位與素材放置尺寸以此為準 |
| 主要視覺區 | **1136×640** | 超出的範圍是出血；關鍵角色、盤面與文字不可依賴出血區 |
| Symbol 交付 | **版面實際放置大小 ×2** | 是「放置尺寸的兩倍」，不是把原出圖再乘兩倍 |
| 其他素材交付 | **1:1** | 背景、UI、角色、JP 條等常態素材皆依實際需求尺寸 |
| Spine 圖 | **不由美術先壓縮** | 交給程式在 Cocos Creator 統一壓縮，避免二次壓縮造成畫質損失 |
| 特殊大螢幕需求 | 另出放大版 | JP 條常態仍為 1:1；只有展覽等放大場合才另外出 2× 版本 |

不可套用研二的 1400×640 或背景可自行縮成 0.5 倍等規範。這是研一專案，尺寸基準不同。

### 8.4 配色、調性與市場方向

- 主市場定位為**東南亞**；整體要明亮、有活力。
- 研一目前偏好**紅金**，也重視寶石元素；寶石應服務價值感與階層，不能平均灑滿所有部件。
- **不要整體都用同一色調。** 主體、角色與 Symbol 使用相近主色時，背景應降低該色的比例，以冷暖、明暗或低彩度色拉開前後。
- 避免深紫與過暗畫面。FG 可以變暗以襯托特效，但不能讓整體長時間沉悶、難辨識。
- 背景需有泛用性，避免在未收到主題設定前加入過度限定單一地區的建築、地標或文化元素。
- 實際主色、節慶氣氛與地區題材等收到新主題文件後再定義。

### 8.5 角色、Symbol、材質與故事一致性

- 角色、Jackpot 角色 Symbol、一般 Symbol、盤框與特效必須屬於同一世界觀，不能各自像不同套 AI 素材。
- 主角與核心道具要能說明玩法故事，例如角色為何操作輪盤、為何道具能揭曉 Jackpot。
- 新主題的故事、角色設定、場景、主色、Symbol 家族與特效語言，等收到主題文件後再補進本規格。
- 材質顏色要合理：岩石、木材、玉石、金屬、寶石應保留各自特性，不能只為配色把材質畫得失真。
- 非人類角色的手、腳、肌肉與關節要保留物種特徵，避免直接套人類身體。
- 頭飾只作點綴，不能比臉、眼神或核心道具更搶眼。
- 風格可參考 Pragmatic Play、PG Soft 的清楚輪廓、商業完成度與 Slot 閱讀性，但不要直接複製題材或角色。
